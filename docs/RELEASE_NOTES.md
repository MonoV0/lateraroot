# Lateraroot v0.8.1 — ガラステスト版

背景のぼかし・縁の屈折・光をGPUで描画する読み取り専用のテスト版です。ZIPをすべて展開して `Lateraroot.exe` を起動します。.NET同梱です。設定は `GlassPreview` に分け、正式版の収納データを使わず、整理・復元も実行できません。

ガラス有効時はウィジェットをキャプチャから除外するため、録画・画面共有に映りません。設定の「背景ぼかし・屈折（テスト）」をオフにすると通常の半透明表示へ戻ります。回転画面など非対応環境でも通常表示に戻ります。Appleのネイティブ素材ではなく、全GPU環境での動作・性能を保証する正式版でもありません。

通常ビルドにはv0.7.3の復元修正も反映しています。全件復元はジャンルや検索から独立し、新規収納は日時フォルダーへ元の名前のまままとめます。

- デスクトップのゲーム用ショートカットを、起動URLや起動先・引数から自動分類します。Steam・Epicなどの既知のゲーム起動情報を判定し、Webリンクやランチャーだけのリンクと区別します。ゲーム本体の検索・移動・起動は行いません。
- 名前・更新日時・種類・サイズの昇順／降順を、右クリック・設定・インスペクターから変更できます。取得済みデータを使い、追加のファイル取得を行いません。ジャンル自体の順番は既存の上下操作で変えられます。
- ジャンルをアイコンだけで表示できます。アイコンはジャンルごとに選べ、名前はホバーと読み上げ用ラベルへ残します。デスクトップとコンパクト表示で共有し、保存前に実際のプレビューを確認できます。
- 新しいゲーム分類を標準のショートカット分類の前へ一度だけ追加します。既存の独自ルール・色・名前を保ち、上限やユーザーの削除操作を尊重します。

コア・通常UI・専用プレビューの読み取り専用制約を自動検証します。物理GPUの合成テスト背景で、屈折とぼかしによる実画素の変化、文字の鮮明さ、背景取得、自己映り込みの回避、更新・再有効化・非表示を検証します。画面は外部へ送信しません。追加のランチャーSDKやバックグラウンドサービスも使いません。
