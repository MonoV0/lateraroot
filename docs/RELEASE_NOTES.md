# Lateraroot v0.8.2 — 開発版

背景を取得してぼかし・屈折させるリキッドグラス描画を削除し、従来の半透明表示へ戻しました。関連する設定、GPUシェーダー、画面取得処理、キャプチャ除外、専用テスト版とそのビルド・検証処理も削除しました。

ゲーム用ショートカットの自動分類、名前・日時・種類・サイズの昇順／降順、ジャンルのアイコンだけの表示とアイコン選択は引き続き利用できます。

全件復元の修正も維持しています。「すべて元に戻す」はジャンルや検索に関係なく履歴全体を復元します。新しい収納は日時フォルダーへ元の名前のまままとめ、旧版のID別フォルダーも復元できます。同名項目は上書きしません。
