# Lateraroot v0.7.0

アニメーションがすべて停止する原因を修正し、コンパクト表示の上部とUIアイコンを整えました。

- Windows側のアニメーションが無効でも、Laterarootでは初期設定から動きを有効にします。Windows自体の設定は変更しません。「動きを減らす」は常に優先し、OSに合わせたい場合は「Windowsのアニメーション設定に合わせる」を選べます。既存の「動きを減らす」設定も保持します。
- ホバー・展開・収納・最小化・非表示・復帰の動きを共通処理にまとめました。遅れて表示するファイルが先に一瞬見える問題を修正し、表示の準備が遅れたセルも展開時の動きへ参加します。後からスクロールしても展開アニメーションを繰り返しません。
- すばやい再ホバー・非表示からの復帰で古い完了処理を破棄します。切替途中で動きを止めても、操作不能な透明ウィジェットを残しません。
- 上部の不透明な白いドラッグ帯を廃止し、グリップと lr. を一つのガラス製ハンドルへ統合しました。ロック時は鍵アイコンになります。コンパクト表示のジャンル名は読みやすい2行表示にしました。
- UIアイコンを **[Uicons by Flaticon](https://www.flaticon.com/uicons)** のBold Roundedへ変更しました。必要な13点だけをコンパイルし、実行時の通信やフォント追加を不要にしています。設定画面にクレジット、配布物に別ライセンスを記載しています。

コア24件・UI214件を検証しました。Windowsのアニメーションがオフの実環境で、強制有効化を使わずに途中・完了・中断を確認しています。四辺配置、正方形、透過と文字のコントラスト、1,500件の仮想化、収納・復元も引き続き検証します。UI検証は分離したデモを使うアプリ内描画で、物理マウス入力のテストではありません。

アプリ内の「更新を確認 → ダウンロード → 更新して再起動」で更新できます（v0.4以降）。設定・収納履歴・実ファイルは保持します。CIでは配布パッケージの更新・再起動・データのハッシュ保持・破損パッケージ拒否も検証します。
