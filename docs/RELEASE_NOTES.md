# Lateraroot v0.4.0

アプリ内アップデートを追加しました。

- 通知領域・設定から「更新を確認 → ダウンロード → 更新して再起動」を実行できます。
- 起動時と1日ごとに新しい正式版を確認して通知します。設定でオフにできます。自動ダウンロード・自動適用はしません。
- ダウンロードの進捗表示、中止、再試行に対応します。破損したパッケージは検証で拒否します。
- 設定・収納履歴・収納ファイルは保持します。ファイル処理中は更新のための再起動を止めます。

v0.3以前からは最初の1回だけ、旧版を終了し、この版のZIPを別フォルダーへすべて展開して起動してください。その後はアプリ内で更新できます。直下の `Lateraroot.exe`、`current`、`packages`、`Update.exe` をまとめて保ってください。

Windows 10/11 x64向け、.NET同梱のポータブル版です。署名はありません。データの保存先は引き続き `%LOCALAPPDATA%\Lateraroot\Data` です。

検証: コア18件、UI91件、実パッケージの更新・再起動、設定・収納データのハッシュ一致、破損パッケージの拒否。テスト専用の次版は公開しません。
