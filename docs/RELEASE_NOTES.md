# Lateraroot v0.7.1

FlaticonのUIアイコン全13点を、細線の **[Thin Rounded](https://www.flaticon.com/uicons/get-started/)** に統一しました。設定、閉じる、最小化、非表示、移動ハンドル、鍵、矢印、検索、再読み込み、追加、上下移動に適用しています。

公式配布の4.0.0を固定し、チェックサムを検証して必要な図形だけを組み込みます。実行時の通信やフォント追加は不要です。設定画面のクレジットとFlaticonの別ライセンスを維持しています。

アプリ内の「更新を確認 → ダウンロード → 更新して再起動」で更新できます。
