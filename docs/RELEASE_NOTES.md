# Lateraroot v0.6.1

Rainmeterの「情報取得・表示・操作を分ける」「必要なときだけ更新する」「配置を管理する」仕組みを、デスクトップアイコン整理に絞って取り入れました。

- ファイル情報をバックグラウンドで取得し、デスクトップ表示とコンパクト表示で共有します。同時取得を一つにまとめ、古い結果を反映しません。
- 検索・並べ替えは取得済みデータを使います。変更のないカテゴリを作り直さず、別ジャンルの変更で開いている一覧を置き換えません。
- 非表示・最小化中は新しい読み込みを保留し、表示を戻すと更新します。
- v0.6.1では、既に読み込み中でも、非表示・最小化中の通知から追加取得を開始しないよう調整しました。
- 「一覧を再読み込み」を右クリック・通知領域・F5に追加しました。ファイル監視も張り直します。
- 「配置をロック」を右クリック・通知領域・設定の「配置と動作」に追加しました。すべての移動ハンドルを止め、ファイルの展開・起動は維持します。設定画面からの配置変更は可能です。
- 整理の確認待ち中の重複操作と、確認・実行中の更新再起動を防ぎます。

時計・天気・CPU監視・Lua・プラグイン・スキン言語などは追加していません。既存のWPF描画・JSON設定・収納ライブラリを再利用します。Rainmeterのコードを組み込まず独立して実装しています。対応表は [設計資料](https://github.com/MonoV0/lateraroot/blob/main/docs/ARCHITECTURE.md) を参照してください。

白・黒の標準カラー、任意ジャンル・色編集、Liquid Glass風の半透明素材、収納・復元、アプリ内アップデートは引き続き利用できます。既存の設定・収納ファイルは保持します。

v0.4以降は「更新を確認 → ダウンロード → 更新して再起動」で更新できます。v0.3以前は旧版を終了し、新しいZIPを別フォルダーへすべて展開してください。

検証: コア24件・UI184件。取得の直列化・古い結果の破棄・不変データ・失敗後の再試行、実フォルダー通知、変更のない表示の保持、非表示／最小化からの復帰、配置ロック、手動再読み込みを確認しています。CIでは実パッケージの更新・再起動・設定／収納データのハッシュ保持・破損パッケージ拒否も検証します。
