# Lateraroot v0.7.2

最小化の記号が細すぎて見えにくい問題を修正しました。Flaticon Thin Roundedの形を保ちながら、最小化だけ表示サイズに合わせた太さ補正を入れています。

下部の設定・最小化・非表示から個別の盛り上がったガラス枠を外し、一つの操作エリアにまとめました。ホバー・キーボードフォーカス・押下時の反応と、操作できる領域は維持します。最小化から戻す操作も同じ見た目にそろえました。

現在のガラス素材は半透明・縁・静的反射による表現です。背景の屈折には背景を参照するGPU描画への改修が必要です。現状との差と実装条件を設計資料へ明記しました。

アプリ内の「更新を確認 → ダウンロード → 更新して再起動」で更新できます。
