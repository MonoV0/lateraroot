# Lateraroot v0.5.0

白・黒を標準にしたLiquid Glass風の質感と、ジャンル・色を選びやすい設定画面を追加しました。

- 正方形ウィジェット・ファイル・コンパクト表示に、半透明の着色、光沢の縁、反射を重ねた共通素材を採用しました。形と既存の展開アニメーションは保持します。
- 新規設定の標準カラーは白と黒です。保存済みのジャンル・色・収納ファイルは引き継ぎます。
- 設定の「ジャンルと色」で、ジャンル名・色見本・任意の色選択・HEX入力・分類ルールをライブプレビュー付きで編集できます。追加・並べ替え・削除にも対応します。
- 「全色を白・黒に戻す」で、名前や分類ルールを保って色だけをリセットできます。旧版のカラーからの切り替えにも使えます。
- 「配置と動作」に「透明効果を減らす」を追加しました。Windowsのハイコントラスト時も不透明にします。編集中の変更は保存まで反映しません。

Windows向けのWPF素材表現です。AppleのネイティブLiquid Glassや背景のぼかし・屈折処理は含みません。背景のキャプチャや常時ぼかしは使わず、凍結した描画リソースを上限付きで共有します。

v0.4からはアプリの「更新を確認 → ダウンロード → 更新して再起動」で更新できます。v0.3以前は旧版を終了し、新しいZIPを別フォルダーへすべて展開してください。データの保存先は `%LOCALAPPDATA%\Lateraroot\Data` のままです。

検証: コア19件・UI169件。ガラスの実透過・不透明フォールバック、代表色の明暗背景での4.5:1以上の文字コントラスト、ジャンル・色の編集と保存、既存のウィジェット・ファイル操作・アプリ更新を確認しています。CIでは実パッケージの更新・再起動・収納データのハッシュ保持・破損パッケージ拒否も検証します。
