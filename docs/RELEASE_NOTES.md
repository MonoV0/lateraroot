# Lateraroot v0.7.3

「デスクトップを整理」は全ジャンルを収納する一方、「元に戻す」は選択中のジャンルに限定されていた問題を修正しました。「すべて元に戻す」は検索やジャンルに依存せず、収納履歴全体を復元します。表示一覧から除外された項目も対象です。

新しい収納は `Vault/整理日時/元の名前` にまとめます。ファイルごとのランダムなフォルダーを作らず、同じ操作で収納したファイルとフォルダーの関係を保ちます。旧版の収納履歴もそのまま復元できます。同名ファイルは上書きせず、別名で復元します。

手動で戻した項目の履歴を整理し、収納先にも元の場所にもない項目はエラーを表示して履歴を保持します。復元後は空になった収納用フォルダーだけを削除します。

通知領域の「更新を確認 → ダウンロード → 更新して再起動」で更新できます。設定・収納データの保存先は変わりません。
