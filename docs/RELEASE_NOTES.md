# Lateraroot v0.8.3
+
+ライト／ダークのカラーモードを追加しました。設定の「配置と動作」→「カラーモード」で選び、「保存する」で反映できます。選択中は設定画面で見た目を確認でき、キャンセルでは全体のモードを変えません。保存すると設定・更新画面、検索・整理パネル、コンパクト表示の操作部分へ反映し、次回起動時も引き継ぎます。ジャンルごとの色は保持します。
+
+背景取得・ぼかし・屈折を使うリキッドグラスのテスト実装は削除しました。追加の常駐処理や描画エンジンを使わず、共通の配色リソースを切り替えます。
+
+ゲーム用ショートカットの自動分類、ファイルの昇順／降順、ジャンルをアイコンだけで表示する設定とアイコン選択も含みます。
+
+全件復元の修正を維持しています。「すべて元に戻す」はジャンル・検索に依存せず、収納履歴全体を復元します。新規収納は日時フォルダーへ元の名前でまとめます。旧版の収納履歴にも対応し、同名項目は上書きしません。
+
+アプリ内の「更新を確認 → ダウンロード → 更新して再起動」で更新できます。
+
